# 3D Model Directory

Place your BMI270 sensor 3D model here.

Recommended format: GLB (2MB with 1k textures)
Filename: model.glb

The model will be used to visualize sensor motion data in real-time.

To add your model:
1. Download the GLB format (2MB, 1k textures) from your source
2. Rename it to "model.glb"
3. Place it in this directory
4. Run `flutter pub get` to ensure assets are recognized
